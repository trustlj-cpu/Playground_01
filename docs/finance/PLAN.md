# 데일리드롭 파이낸스 계획 (2026-10-25, 사장님 지시 반영)

## 확정 사항
- 주소: `/finance/kor/` (판은 `/finance/kor/<날짜>/` 장 전, `/finance/kor/<날짜>-pm/` 마감 후). 미국·일본은 `/finance/usa/`, `/finance/jpn/` (추후).
- 1단계는 한국(KR)만. 하루 2판: 장 시작 1시간 전(08:00 KST), 마감 1시간 후(16:30 KST). 휴장일에도 판은 내되 시장에 영향을 줄 새 뉴스로 채움(없으면 작은 판).
- 기관 의견(추천·전망·목표가)은 출처 있는 인용만. 우리 의견 없음.
- 로고: 기존 로고는 그대로, 우측 하단에 "FINANCE" 청녹 단색 배지만 얹음. 배지를 누르면 파이낸스로.
- 전환: 로고 배지, "데일리드롭 | 파이낸스" 전환 스트립, 메인의 "오늘의 파이낸스" 칸, 로고·페이지 좌우 스와이프(가장자리·가로 스크롤·팝업 제외), 첫 방문 안내. 오른쪽 가장자리 탭은 쓰지 않음.
- 소문·커뮤니티 섹션: 확인 안 됨 표기, 출처·시각, 인기글·언론이 다룬 풍문만. 법적 쟁점은 LEGAL_REVIEW.md.
- 숫자 오류 가능성 상시 고지.

## 공개 전환 스위치
- 빌드 환경변수 `DD_FIN_PUBLIC=1` 이면 모두에게 보임. 기본은 숨김.
- 숨김 상태에서는 주소 뒤에 `?fin=1` 을 붙여 연 브라우저에서만 보임(`?fin=0` 으로 끔). `/finance/kor/` 는 noindex.

## 단계
1. (이번) 틀: 배지, 전환 스트립, 메인 칸, 스와이프, `/finance/kor/` 시험판(자리 안내), 금융·소문 수집 소스 31개 추가.
2. 데이터: 시세 종목 확장(분할 호출), 마감 저장(finance_daily), 일정·공시·수급, 판 작성용 묶음.
3. 작성: 파이낸스 전용 spec/render/check(추천·전망 금지, 숫자는 시세표만, 숫자 대조 검토), 장 전·마감 후 예약.
4. 연결: 기존 경제 기사 팝업 하단의 "파이낸스에서 더 보기" 줄, 분류 표시 옆 FIN.

## 지면 규칙(작성 에이전트용, 3단계에서 SPEC에 편입)
- 시세·퍼센트·종목명은 시세표 값만. 에이전트가 계산하거나 지어내지 않는다.
- 금지: 사라/팔라, 유망·추천·수혜 종목 리스트, "오를 것/내릴 것" 단정, 우리 의견 칸.
- 허용: 증권사·기관의 목표가·투자의견 변경 사실(누가·언제·무엇), 상반된 의견 병기.
- 소문 섹션: 항목마다 출처·시각·"확인 안 됨", 공식 부인·정정 병기, 단독·저반응 글 제외.
- 용어는 어려운 말만(기존 규칙 유지).
