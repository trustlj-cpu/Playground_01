1) GitHub 저장소 trustlj-cpu/playground_01 을 붙이고 paycheck-page 브랜치로 체크아웃해라(main 에는 절대 push 금지, PR 은 시킬 때만).
2) docs/handover/ACCOUNT_SWITCH_HANDOFF.md 를 끝까지 읽고, 그 문서 「0. 처음 할 일」을 순서대로 해라:
   - SESSION_02_HANDOVER.md·ops/autoed/SPEC.md·ops/TRANSLATE_DESK.md 읽기
   - GitHub push·Cloudflare D1 연결 확인
   - 예약 작업 6개를 이 세션 대상으로 새로 만들기(부록 A 프롬프트, 미국은 CRON_TZ=America/New_York)
   - 번역 방식 준비
3) 판을 만들기 전에는 항상 그 판 파일이 origin/paycheck-page 에 이미 있는지 확인하고, 있으면 건너뛰어라(원 계정과 중복 방지).

5) 운영하면서 그 문서 맨 아래 「새 계정 운영 기록」을 계속 채우고, 되돌려줄 때는 「되돌려주기」 절차대로 하라(기록 커밋 → 새 계정 예약 작업 모두 끄기 → 사장님께 알림).
