### 안 넣은 것 / 처리한 것
- 실제 기사에는 실존 인물 이름과 매체 이름이 나오므로, 캡처한 1면에서 **제호·시세·날짜줄만 선명하게 두고 기사 영역은 흐림 처리**했습니다(문장이 읽히지 않음).
- "1위", 이용자 수, 수상 등 입증 못 하는 표현은 쓰지 않았습니다.
- 아침 6시·저녁 6시는 사이트의 현지 06:00 / 18:00 발행 규칙에 맞춘 문구입니다. 발행 시각이 바뀌면 문구도 바꿔야 합니다.

## 3. 업로드 순서 (Google Ads)

**AdSense는 광고를 "게재하는(수익을 받는)" 서비스라 광고 집행에는 쓰지 않습니다.** 광고주 계정은 ads.google.com 에서 따로 만듭니다.

1. ads.google.com 에서 Google Ads 계정 생성(전문가 모드 권장), 결제 정보 등록. 언어별로 캠페인을 나누고 타깃 국가·언어를 맞춥니다(한국어-대한민국, 영어-미국, 일본어-일본).
2. **YouTube 영상 (Video 캠페인 / Demand Gen)**
   1. YouTube Studio 에서 `video/` 의 mp4를 **미등록(Unlisted)** 으로 업로드 (세로는 Shorts 로도 쓰입니다. 제목·설명에 사이트 주소 포함).
   2. Google Ads -> 캠페인 만들기 -> 목표 선택(웹사이트 트래픽 등) -> 유형 **Demand Gen**(세로·가로 영상, 이미지 모두 사용) 또는 **동영상**.
   3. 광고 만들기에서 업로드한 영상 URL 붙여넣기, 위 제목·설명, 최종 URL, 버튼 문구 입력.
   4. 일일 예산, 타깃(국가·언어)을 정하고 게재.
3. **디스플레이 (반응형 디스플레이 광고)**
   1. 캠페인 유형 **디스플레이**(웹사이트 트래픽 목표) 선택.
   2. 광고 만들기 -> 반응형 디스플레이: 이미지에 `1200x628`(가로), `1200x1200`(정사각형)을 올리고, 필요하면 `960x1200`(세로 4:5)도 추가. 로고는 `site/brand/` 의 아이콘/로고 사용.
   3. 제목 5개·설명 3개·최종 URL 입력.
   4. `300x250`, `728x90`, `320x50` 은 **이미지 광고(업로드형)** 로 올릴 때 사용합니다(각 150KB 이하, 현재 모두 40KB 이하).
4. 승인 검토에는 보통 1영업일 안팎이 걸립니다. 승인 후 클릭·전환을 보면서 소재를 교체하세요.

## 4. 확인할 점
- 큰 배너 3종(1200x628, 1200x1200, 960x1200)은 파일이 150KB를 넘지만(약 0.2~0.3MB), 반응형 디스플레이 이미지 한도(5MB)에는 문제없습니다.
- 기사 영역을 흐림 처리해서 "실제 1면 모양"만 보입니다. 선명한 기사 화면을 쓰려면 인물·매체 이름을 직접 확인한 뒤 `src/shots.js` 의 `CSS` 를 고치세요.
- 폰트는 Google Fonts(Noto Serif)를 쓰고, 로고는 `site/brand/logo-ink.svg` 입니다.
